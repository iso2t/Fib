# Fib

This project is the test project for the creation of the
[Cloth Compiler](https://github.com/Cloth-Foundation/cCloth) first iteration.

At its very core, it is basically just a fibonnaci sequencer, however, it uses
many new features being implemented in the langage. This allows me to:

1. Test the implementation to ensure we are getting expected results.
2. Test the actual language to see if it feels right.
3. Find any buggy behaviors or slow builds from Shuttle.

Cloth is still a language under development. This example may not fully cover all
possible implementations of the language, or may not be fully up to date with newer
code basis.
